# Open WebMCP Challenge 規則摘要

主辦：Devpost

核心要求：
- 使用 WebMCP API 建立 Web 應用
- 展示人與瀏覽器 Agent 的協作
- 提交三分鐘 Demo 影片
- 原始碼公開

評分標準：
- WebMCP Leverage：是否善用 WebMCP 特有能力
- Execution：產品完成度與可操作性
- Potential：未來發展可能性

限制：
- 不得提交已存在的完整產品
- 可以使用既有技術，但 WebMCP 整合必須是新工作
