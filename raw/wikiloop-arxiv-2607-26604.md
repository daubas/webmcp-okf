# WikiLoop: Jointly Learning to Build and Navigate Agent-Native Wikis

WikiLoop 將知識庫的建造與使用接成迴圈：

- Navigator 使用 Wiki 回答問題
- Builder 根據查詢中遇到的困難修改 Wiki
- 修改只在使之後更容易找到完整答案時才有價值

核心洞見：知識庫不應只因有新資料就膨脹，應根據實際使用中遇到的問題改善。

啟示：WebMCP 的 read 工具使用紀錄可以回饋給維護 Agent，找出知識缺口。
