# WebMCP Challenge

Open WebMCP Challenge 是 Devpost 上舉辦的開發競賽，主題是使用 WebMCP 建立能讓人與瀏覽器 Agent 共同操作的 Web 應用。

## 核心問題

比賽要求參賽者回答：

> 人與 Agent 現在能共同完成什麼以前困難或不可能完成的事？

## 評分重點

- WebMCP Leverage：是否充分運用 WebMCP 的能力，而非只是普通 Web App
- Execution：產品是否可實際操作
- Potential：是否有持續發展的可能性

## 提交要求

- 三分鐘以內的 Demo 影片
- 可運作的 Web 應用
- 原始碼（GitHub 或其他平台）
- 文字說明

## 對工具設計的啟示

參賽作品不應只註冊一兩個簡單查詢工具。理想的 WebMCP 應用應具備：

- 多個讀寫工具，涵蓋完整工作流程
- 有狀態的操作（搜尋、比較、組合、提交、確認）
- 需要人類判斷的操作明確保留給 UI
- Agent 與人看到同一份即時狀態
